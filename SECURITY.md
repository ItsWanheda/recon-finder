# Security Policy

## 🔐 Recon-Finder Security Policy

Thank you for helping improve the security of **Recon-Finder**.

Recon-Finder is a reconnaissance and HTTP discovery tool intended for authorized security testing, research, and educational use.

We take reports about vulnerabilities in the project seriously.

---

## 📌 Supported Versions

| Version   | Supported |
| --------- | --------- |
| `0.1.x`   | ✅ Yes     |
| `< 0.1.0` | ❌ No      |

Security fixes are generally applied to the latest supported release.

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability in Recon-Finder, please **do not open a public GitHub issue** with sensitive details.

Instead, report the issue privately through GitHub's security reporting functionality if it is enabled for the repository.

Your report should include:

* A clear description of the vulnerability
* The affected version
* Steps required to reproduce the issue
* Expected behavior
* Actual behavior
* Potential security impact
* Relevant logs, screenshots, or proof of concept when appropriate

Please avoid including secrets, credentials, personal information, or unrelated sensitive data.

---

## 🧪 Responsible Testing

When testing Recon-Finder:

* Only test systems you own or have explicit permission to assess.
* Use isolated environments when possible.
* Do not use real credentials in proof-of-concept material.
* Do not intentionally access or disclose sensitive information.
* Keep testing non-destructive.
* Respect applicable laws and authorization boundaries.

Recon-Finder is designed for **discovery**, not exploitation.

---

## 🔎 Scope

Security reports are particularly relevant to:

* Command execution vulnerabilities
* Unsafe input handling
* Path traversal
* Dependency vulnerabilities
* Malicious wordlist handling
* URL parsing issues
* Request-handling vulnerabilities
* Credential or secret exposure
* Unsafe file operations
* Supply-chain risks

---

## ⏱️ Response

We will make a reasonable effort to:

1. Acknowledge valid reports.
2. Investigate the reported issue.
3. Determine its security impact.
4. Develop and test a fix when necessary.
5. Release an appropriate update.

Response times may vary depending on the complexity and severity of the issue.

---

## 📢 Public Disclosure

Please allow reasonable time for a vulnerability to be investigated and addressed before publicly disclosing technical details.

Coordinated disclosure helps protect users while a fix is being developed.

---

## 🙏 Thank You

Responsible security research helps make Recon-Finder safer for everyone.

Thank you for reporting vulnerabilities responsibly.
