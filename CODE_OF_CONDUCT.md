# Contributor Covenant Code of Conduct

## Our Pledge

We as members, contributors, and maintainers of the Recon-Finder project pledge to make participation in our community a welcoming, respectful, and harassment-free experience for everyone.

We are committed to creating an environment where people can contribute regardless of background, experience level, identity, or perspective.

---

## Our Standards

Examples of behavior that contribute to a positive environment include:

* Being respectful and considerate.
* Communicating clearly and constructively.
* Welcoming questions and different perspectives.
* Providing useful technical feedback.
* Accepting constructive criticism.
* Focusing on the technical issue rather than the individual.
* Taking responsibility for mistakes.
* Respecting project boundaries and security policies.

---

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or discrimination.
* Personal attacks or insults.
* Trolling or deliberately disruptive behavior.
* Threats or intimidation.
* Publishing private information without permission.
* Sexualized comments or unwanted advances.
* Deliberate attempts to derail technical discussions.
* Malicious behavior toward contributors or project infrastructure.
* Using project resources to target systems without authorization.

---

## Security and Responsible Use

Recon-Finder is a security reconnaissance project.

Contributors must respect the project's intended use.

Do not use project infrastructure, issue trackers, discussions, or contributions to facilitate:

* Unauthorized access
* Credential theft
* Malware distribution
* Destructive activity
* Privacy violations
* Attacks against systems without authorization

Security vulnerabilities in the project should be reported according to `SECURITY.md`.

---

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing the standards described in this Code of Conduct.

Maintainers may take appropriate action in response to unacceptable behavior, including:

* Removing inappropriate content
* Issuing warnings
* Temporarily restricting participation
* Permanently restricting participation
* Reporting serious incidents to appropriate authorities when required

Enforcement decisions should be made fairly and consistently.

---

## Scope

This Code of Conduct applies within project spaces, including:

* GitHub repositories
* Issues
* Pull requests
* Discussions
* Project-related communication
* Other spaces when an individual is officially representing the project

---

## Reporting Issues

If you experience or witness unacceptable behavior, report it privately to the project maintainers through the appropriate GitHub reporting channel.

For security vulnerabilities, **do not use public issues**. Follow the process described in [`SECURITY.md`](SECURITY.md).

Please provide enough information to allow the maintainers to understand and investigate the situation.
